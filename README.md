# Afrilink Legal & Advisory Website

This is the Vercel-ready website package for Afrilink Legal & Advisory.

## Deploy on Vercel
1. Upload all these files to your GitHub repository.
2. Go to Vercel.
3. Import the repository.
4. Framework preset: Vite.
5. Build command: npm run build.
6. Output directory: dist.
7. Deploy.

## Important edits
- Replace the WhatsApp number in `src/main.jsx`.
- Replace the Calendly link when your real Calendly page is ready.
